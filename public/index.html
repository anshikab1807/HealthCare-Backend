Healthcare REST API Specification
All available endpoints & status codes
Method Endpoint Authentication Description Expected Status
GET /health Public Server health check and database connectivity ping 200 OK
POST /api/auth/register Public Register a new user (email, password, optional name) 201 Created, 409 Conflict
POST /api/auth/login Public Authenticate user and return accessToken + refreshToken 200 OK, 401 Unauthorized
POST /api/auth/refresh Public Exchange refreshToken for a fresh accessToken 200 OK, 401 Unauthorized
GET /api/patients Bearer JWT List all patients belonging to the authenticated user 200 OK, 401 Unauthorized
POST /api/patients Bearer JWT Create a new patient record (firstName, lastName, birthDate) 201 Created, 400 Bad Request
GET /api/patients/:id Bearer JWT Retrieve specific patient owned by authenticated user 200 OK, 404 Not Found
PUT /api/patients/:id Bearer JWT Replace patient data 200 OK, 404 Not Found
PATCH /api/patients/:id Bearer JWT Partially update patient fields 200 OK, 404 Not Found
DELETE /api/patients/:id Bearer JWT Delete patient owned by user (cascades mappings) 200 OK, 404 Not Found
GET /api/doctors Bearer JWT List all registered doctors 200 OK
POST /api/doctors Bearer JWT Create a doctor (firstName, lastName, specialty) 201 Created, 400 Bad Request
GET /api/doctors/:id Bearer JWT Retrieve doctor by ID 200 OK, 404 Not Found
DELETE /api/doctors/:id Bearer JWT Delete doctor (cascades mappings) 200 OK, 404 Not Found
POST /api/patients/:patientId/mappings Bearer JWT Assign a doctor to an owned patient 201 Created, 409 Conflict
GET /api/patients/:patientId/mappings Bearer JWT List all doctors assigned to patient 200 OK, 404 Not Found
